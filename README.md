Nebula Gaming es una plataforma de chat en tiempo real enfocada en la comunidad gamer, desarrollada como proyecto académico para la materia Taller de Diseño Multimedia.

El sistema permite la creación y administración de canales de comunicación entre usuarios y administradores, ofreciendo una experiencia moderna e interactiva inspirada en plataformas de mensajería para videojuegos.

Características principales
✅ Registro e inicio de sesión de usuarios
✅ Sistema de autenticación
✅ Panel administrativo
✅ Creación y edición de canales
✅ Chat en tiempo real
✅ Scroll automático de mensajes
✅ Gestión de usuarios
✅ Diseño responsive
✅ Validaciones de formularios
✅ Protección contra nombres largos en canales
✅ Interfaz moderna orientada a gaming

Instalación del proyecto
1. Clonar repositorio
git clone https://github.com/juandiegobb/TDM_Nebula_Gaming.git
2. Instalar dependencias
npm install
3. Añadir archivo .env (Leer .env.example)
4. Ejecutar proyecto
   npm src\server.js
